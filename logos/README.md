# Logos

- `xpander-1.png`: logo original recibido, en PNG con fondo. No es un archivo vectorial.
- `brand/`: versiones con fondo transparente preparadas para la web (ver `brand/USO.md`). Las que usa la tienda por defecto están en `public/brand/`; el propietario puede reemplazarlas desde Datos del negocio.
- `chi/`, `logo1/` a `logo5/`, `logo5.jpeg`, `logo7.jpg`: bocetos y alternativas de trabajo.

Son material de consulta: no se incluyen en las imágenes Docker ni llegan al servidor (`.dockerignore`).
